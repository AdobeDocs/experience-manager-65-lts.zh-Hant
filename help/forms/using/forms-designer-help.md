# Forms Designer說明 {#form-designer-help}

AEM Forms Designer是一款案頭應用程式，可在Adobe Experience Manager Forms中製作和管理PDF和XFA型調適型表單。 使用下列資源開始使用、探索範例，並參考Designer針對此6.5 LTS版本的指令碼功能。

* [使用Designer](https://www.adobe.com/go/learn_aemforms_designer_65_lts) - Designer工作區的概觀與核心撰寫概念。
* [Designer快速入門教學課程](https://www.adobe.com/go/learn_aemforms_designer_quick_start_65_lts) — 開始使用Designer的逐步教學課程。
* [Designer範例](https://www.adobe.com/go/learn_aemforms_designer_samples_65_lts) — 可在Designer中開啟和調整的可下載範例表單。
* [Designer指令碼基本知識](https://www.adobe.com/go/learn_aemforms_scriptingBasics_65_lts) - Designer表單指令碼簡介。
* [Designer指令碼參考](https://www.adobe.com/go/learn_aemforms_scriptingReference_65_lts) - Designer中指令碼物件與方法的完整參考。
* [Designer FormCalc參考](https://www.adobe.com/go/learn_aemforms_formCalc_65_lts) - Designer的內建計算語言FormCalc的完整參考。
